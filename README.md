# 🎯 Customer RFM Segmentation & A/B Testing

## 📌 Project Overview
This project applies statistical modeling and exploratory data analysis (EDA) to evaluate customer purchasing behaviors and determine the effectiveness of marketing campaigns.

## 🛠️ Tools & Technologies
* **Python:** Core programming language.
* **Pandas & NumPy:** Data manipulation, aggregation, and statistical calculations.
* **Matplotlib:** Time-series and segmentation visualization.

## ⚙️ Methodology
* **RFM Modeling:** Engineered a Recency, Frequency, and Monetary (RFM) model to categorize customers into distinct value tiers (e.g., VIPs, At-Risk, New Customers).
* **A/B Testing:** Evaluated marketing campaign results using statistical significance testing to derive actionable insights.
* **Time-Series Evaluation:** Forecasted seasonal purchasing behaviors based on historical transaction logs.

## 📊 Key Business Insights
* Successfully segmented the customer base to allow for highly targeted, ROI-driven marketing interventions.
* Validated campaign performance through rigorous statistical A/B test evaluation.
